# CMSI 3801 Classroom

A collection of starter files and unit tests for my CMSI 3801 course at LMU.

## Using the tests

Homework submissions will be run against the tests provided here, so you’re encouraged to bring them into your own repository and run them. All tests are designed to be run with their respective language folder. Here’s how:

### Lua

```
lua exercises_test.lua
```

### Python

```
python -m unittest exercises_test.py
```

(You may have to replace `python` with `python3` on some machines.)

### JavaScript

```
node --test exercises.test.py
```
